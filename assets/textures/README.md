# Текстуры

Положи сюда файл:

```text
dungeon_atlas.png
```

Это должен быть spritesheet/texture atlas с рыцарем, скелетами, магом-скелетом, бронированными скелетами, тайлами пола, стенами и предметами.

Игра автоматически ищет файл по пути:

```text
assets/textures/dungeon_atlas.png
```

Если файла нет, проект продолжит работать на резервной отрисовке примитивами.
